- [x] Portable orchestration contract

## Candidate hardening

- [ ] Pass critical acceptance scenarios on three materially different UNPS workflows
- [ ] Add sanitized golden-output examples
- [ ] Validate package portability across two compatible agent environments
- [ ] Measure startup-context reduction against the previous monolithic approach
- [ ] Test failure behavior when connectors and dependencies are unavailable
- [ ] Complete live repository-intelligence promotion test

## Production gate

Production requires:

1. Repeatable acceptance passes
2. No unresolved critical security or routing defects
3. Verified install path
4. Versioned change control
5. Human-readable navigation
6. Demonstrated reduction in duplicate work and context waste

## Later exploration

- Signed package manifests
- Automated link and manifest validation
- Public starter agent template
- Connector-profile compatibility matrix
- Agent-package visualizer
- Release bundles for supported harnesses

Roadmap items are directional and may change based on real UNPS workflow evidence.
