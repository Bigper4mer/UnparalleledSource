# HiveForge First-Run Prompt

Copy and paste this into the AI environment where HiveForge is loaded.

```text
I just installed UNPS HiveForge. Treat this as my first-run onboarding session.

1. Confirm the HiveForge startup files and explain the system to me at the level that matches my experience.
2. Run the minimum useful startup intake. Learn my work role, top goals, expected recurring work, experience level, preferred explanation/detail level, tools/source systems I actually use, file/workspace locations, and autonomy/approval preferences.
3. Do not ask for or store passwords, API keys, tokens, private keys, authentication cookies, regulated data, or unrelated sensitive personal information.
4. If this is an existing project, inspect its current human-readable structure before proposing new files or folders. Identify the source of truth.
5. Separate what you learn into:
   - USER WORKING PREFERENCES
   - PROJECT / CLIENT CONTEXT
   - TOOLS AVAILABLE
   - APPROVAL BOUNDARIES
   - CURRENT GOAL
6. Ask me to correct that summary before treating it as durable working context.
7. Recommend the smallest useful HiveForge workflow for my first task and explain why.
8. Tell me which skills/tools you intend to load and which optional capabilities you are deliberately not loading.
9. If information is missing but available through an authorized source, retrieve it rather than making me repeat it.
10. Keep durable state human-readable and learn progressively from validated corrections and repeated successful patterns.

After intake, help me complete one real task end to end and show me the verification evidence.
```

## Fast expert variant

```text
Bootstrap HiveForge on this workspace. Inspect existing project instructions and source of truth, load my validated working preferences if available, classify the task depth, choose the minimum workflow/capability set, state material substitutions or unavailable dependencies, and proceed through the appropriate verification gate. Keep project state human-readable and do not globalize project-specific learning.
```
